# Hallowell
 Metroidvania Game

Commit Syntax:
----------------
va.b.ct- d
-In depth desc
----------------

a - Major version (playable)
b - Minor versions/patches (playable)
c - Commit/update number (playable/buggy)
d - Very high level title/description
t - Type of version
    - Nothing = default
    - a = alpha (incomplete inmplementation)
    - b = Version with build
    - t = testing version (prototyping new ideas or otherwise loosely project related activities)
