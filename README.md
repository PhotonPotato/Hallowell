# **Hallowell**
This is my current hobby project: a linear 2D gory hack-and-slash focused on clean, fast-paced movement.
Inside, you can find all my art assets as well. \
<br>

## To Build
If you have Unity editior version 6 or higher, you should be able to make a fresh build using the following steps:
- File -> Build Profiles
- Choose your desired platform
- Build or Build and Run
- Executable will be in the named folder
<br>

## Controls
Move - WASD \
Jump - Space \
Attack - Left Click \
Grapple - F \
Reset Player Pos - R \
<br>

## Some Cool Stuff (Look in "Level 2" Scene)
- Completely procedural boid enemy (under junk testing parent in the hierarchy)
- Custom A* pathfinding "tick" that explodes when near player
- Try going right and holding jump or downslashing while stomping an enemy
